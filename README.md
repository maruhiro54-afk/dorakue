# 星灯りの旅人

昔ながらのターン制RPGをイメージした、ブラウザで遊べる小さなオリジナルゲームです。ドット絵・キャラクター・物語はゲーム内の独自表現です。

## 遊び方

このリポジトリをダウンロードし、`index.html` をブラウザで開いてください。ビルドや追加パッケージのインストールは不要です。

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー / WASD |
| 会話・調べる・近くの宝箱を開ける | Space / Enter |
| 戦闘・薬草・宝箱 | 画面上の各ボタン |

画面下の方向ボタンでも移動できます。村で話すとHP・MPが全回復し、毒も治ります。森を探索してレベルを上げ、北東の「夜の番人」を倒し、村へ帰りましょう。

## 機能

- 村・森の探索と村人との会話
- 主人公の歩行・向き、村人の待機、モンスターの跳ね・まばたきのアニメーション
- ターン制バトル、魔法、回復、経験値・レベルアップ、ボス戦
- 斬撃・魔法・突進・ダメージの演出
- 森でランダムに出現する宝箱（未開封は最大3個）
- 宝箱の中身は各25%：薬草1～3個、お金10～50G、毒、モンスター
- 毒は8歩の間、移動するたびにHPが2減少（HP1で止まる）。薬草・村で治療可能
- ブラウザのlocalStorageによる自動保存
- OSの「動きを減らす」設定への対応

## セーブについて

進行・未開封の宝箱・毒の状態は同じブラウザに保存されます。ブラウザやURLが変わるとセーブが共有されない場合があります。ブラウザの保存領域が使用できない環境では保存されません。「はじめから」で保存した冒険をリセットできます。

## 構成

`index.html` にHTML・CSS・JavaScript・Canvas描画をまとめています。外部画像や外部サービスへの依存はありません。

## 確認状況

JavaScriptの構文、移動の補間、戦闘処理、勝敗、宝箱の全4結果、毒の継続・解除・HP下限、宝箱の消費・出現位置を模擬DOM/Canvas環境で自動確認しています。実ブラウザでの目視・操作確認は未実施です。
