# 星灯りの旅人

昔ながらのターン制RPGをイメージした、ブラウザで遊べる小さなオリジナルゲームです。ドット絵・キャラクター・物語はゲーム内の独自表現です。

## 遊び方

このリポジトリをダウンロードし、`index.html` をブラウザで開いてください。ビルドや追加パッケージのインストールは不要です。

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー / WASD |
| 会話・調べる・近くの宝箱を開ける | Space / Enter |
| 戦闘・薬草・宝箱 | 画面上の各ボタン |

画面下の方向ボタンでも移動できます。村で話すとHP・MPが全回復し、毒も治ります。森を探索してレベルを上げ、北東の階段から地下迷宮へ入りましょう。地上〜地下2階のどこかに隠された「星の鍵」を、そのマスで「調べる」を使って見つけ、地下3階の「星の宝箱」を開けるとクリアです。鍵の場所は「はじめから」で冒険を始めるたびにランダムに決まります。村人に話すと、鍵がある階のヒントが聞けます。階段の上では「降りる ▼」「上る ▲」ボタンで階を移動します。

## 機能

- 地上の村・森と地下1〜3階の探索。各階40×26マス、主人公を追うスクロール表示
- 主人公の歩行・向き、村人の待機、モンスターの跳ね・まばたきのアニメーション
- 各階8体の見えるモンスター。主人公が1歩移動すると同じ階の敵も1歩移動し、接触すると戦闘。壁への移動やメニュー操作では敵のターンは進みません
- ターン制バトル、魔法、回復、経験値・レベルアップ。倒したマップの敵は消え、逃げると敵が遠ざかります
- 地下3階の固定ゴール宝箱と、別の階にランダム配置される隠し鍵。鍵はマップに表示されず、歩いて通るだけでは拾えません。魔物を倒すだけではクリアになりません
- 斬撃・魔法・突進・ダメージの演出
- 「調べる」またはSpace / Enterで足元を探索すると、まれに隠された宝箱を発見（地上12%・地下18%）。歩行中には出現しません。同じ場所は一度だけ調査でき、結果を保存します
- 宝箱の中身は各25%：薬草1～3個、お金10～50G、毒、モンスター
- 毒は8歩の間、移動するたびにHPが2減少（HP1で止まる）。薬草・村で治療可能
- ブラウザのlocalStorageによる自動保存
- OSの「動きを減らす」設定への対応

## スマホの操作画面

- 縦画面では方向キーを画面下部に固定し、横画面では右下に配置します。
- マップは空いている画面領域へ縦横比を保って縮小し、常に表示します。
- 方向キーは通常56px、小さい画面では48pxのタッチ領域を確保しています。
- ページ全体はスクロールせず、長いログとコマンドの欄だけスクロールできます。
- 「遊び方」から操作説明と目的を確認できます。
- 画面の切り欠き・ホームバーの余白と、ブラウザの表示領域の高さに対応しています。
- PCの従来の配置、キーボード操作、ゲームロジックは維持しています。

## セーブについて

進行・現在の階・鍵の場所と所持状態・各階のモンスター・調査済みの場所・各階の未開封宝箱・毒の状態は同じブラウザに保存されます。ブラウザやURLが変わるとセーブが共有されない場合があります。ブラウザの保存領域が使用できない環境では保存されません。「はじめから」で保存した冒険をリセットできます。

以前のバージョンのセーブはレベル・所持品などを引き継ぎ、旧マップの宝箱・クリア状態をリセットし、新しい鍵とモンスターを配置します。

## 構成

`index.html` にHTML・CSS・JavaScript・Canvas描画をまとめています。外部画像や外部サービスへの依存はありません。

## 確認状況

JavaScriptの構文、移動の補間、戦闘処理、勝敗、宝箱の全4結果、毒の継続・解除・HP下限、宝箱の消費・出現位置を模擬DOM/Canvas環境で自動確認しています。4マップ全通路の到達可能性、地下3階までの階段往復、階ごとの宝箱分離、同じ場所の再抽選防止、旧セーブの移行も確認しています。敵の移動タイミング・接触・撃破・逃走、鍵のランダム配置・調査限定の発見とセーブ復元、鍵がないとクリアできないことも確認しています。スマホUIはブラウザの表示領域を320×480・320×568・390×844・480×280・568×320・844×390に変更して確認し、ページのはみ出し・マップと方向キーの重なりがないことを確認しました。390×844で方向ボタン操作後もページのスクロール位置が変わらないこと、1280×900でPCの従来配置も確認しています。スマホ実機での確認は未実施です。

再検証はNode.jsで `node test-game.cjs` を実行してください（外部パッケージ不要）。
